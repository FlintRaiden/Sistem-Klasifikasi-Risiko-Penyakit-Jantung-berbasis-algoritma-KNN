Tentang Aplikasi

HeartGuard KNN adalah aplikasi web yang menggunakan algoritma K-Nearest Neighbors (KNN) untuk mengklasifikasikan risiko penyakit jantung berdasarkan 13 parameter klinis pasien.

Model dilatih menggunakan dataset Heart Disease UCI yang berisi 1.025 data pasien. Proses preprocessing menggunakan StandardScaler karena KNN sangat sensitif terhadap skala fitur. Nilai K optimal ditentukan menggunakan Elbow Method dengan 5-fold cross-validation.

Coba Sekarang
Cara Kerja KNN
  1. Tentukan nilai K
    Jumlah tetangga terdekat yang akan digunakan untuk voting.
  2. Hitung jarak Euclidean
    Hitung jarak data baru ke semua data latih (setelah scaling).
  3. Pilih K tetangga terdekat
    Urutkan jarak dan ambil K data dengan jarak terkecil.
  4. Voting mayoritas
    Kelas terbanyak dari K tetangga menjadi hasil prediksi.

Fitur Aplikasi

Form Input Interaktif

Masukkan 13 parameter klinis pasien melalui form yang mudah digunakan dengan dropdown dan input numerik yang intuitif.

Visualisasi Probabilitas

Hasil prediksi dilengkapi visualisasi progress bar probabilitas "Sehat" vs "Sakit Jantung" dari voting K tetangga.

Ringkasan Data Pasien

Halaman hasil menampilkan ringkasan lengkap data yang diinput beserta label yang mudah dibaca (bukan kode angka).
